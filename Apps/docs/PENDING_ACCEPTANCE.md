# Aether Pending Acceptance Checklist

## 当前重点验收（2026-03-14）

- [ ] 【拖拽命令实际生效】说出“开始拖拽 / 结束拖拽”后，不仅要在使用统计中识别成功，还要真正进入/退出拖拽状态；开始拖拽后，真实鼠标移动和头控移动都应能持续拖动目标
说明：本轮已补上持续拖拽事件注入，并在开始拖拽时同步系统光标坐标；但仍需重点验证不会重复进入拖拽、一次“结束拖拽”即可稳定放下，以及拖拽中的鼠标位置/视觉反馈不再闪烁错位。

- [x] 【输入开 / 控制关 HUD 收口】在“语音输入开、语音控制关”时，HUD 只应在焦点位于输入框时显示；离开输入框后应立即收起，不应因旧状态、鼠标、常驻/唤醒词启动流程或录音流程再次冒出输入 HUD
说明：已收紧常驻 dictation-only 的等待输入框逻辑，但仍需重点回归“App 启动即常驻”“唤醒词模式”“非输入框场景”这几条链路；当前仍偶发出现“没有输入框却显示 HUD / 提示未检测到输入框”的问题。

## 历史功能，待后续统一回归

- [ ] 【头势识别】点头/摇头的稳定性、阈值和误触控制需要再做一次完整回归
- [ ] 【头势提示音】点头/摇头成功后的提示音需要确认体验是否合适
- [ ] 【耳机按钮动作】耳机单击/双击/三击不应再触发 Aether 动作
- [ ] 【浏览器全屏视频 HUD】浏览器全屏播放视频时 HUD 应自动隐藏，退出后应恢复
- [ ] 【浏览器普通全屏误隐藏】普通网页全屏不应误触发 HUD 隐藏

## 已验收项目存档

- [x] 【输入模式下命令前缀不应误改文本】在输入模式里说“命令全选 / 命令复制 / 命令粘贴”等命令时，不应先把 partial 当成普通输入打进输入框，再因回滚把现有文本误删；语音统计中也不应出现与实际行为不一致的“清空输入”错觉
说明：已收紧 `clearInput` 的模糊/拼音匹配，并新增“显式命令前缀 partial 不做流式输入”的保护，需重点验证输入框内命令执行时不再误清内容。

- [x] 【输入/控制分路一致】“语音输入开、语音控制关”时，只允许在输入框内显示并执行输入；“语音输入关、语音控制开”时，应始终保持控制态 HUD 跟随鼠标并响应控制，不应在输入框里误显示输入 HUD
说明：双开关模型已拆开，但仍需重点验证 HUD 展示、录音入口和最终执行路由三者完全一致，不再出现“HUD 是一套、实际执行是另一套”。

- [x] 【连续一句话不应被过早拆段】在连续说完整一句话、用户中间没有停顿时，后台不应把它拆成多个独立片段；输入结果、使用统计和命令路由都应尽量对应同一条连续语句
说明：已移除 `tickContinuous()` 中额外的“1 秒 transcript 不变就 finalize”逻辑，并让 `EOSDetector` 在 partial 持续变化时刷新语音活动时间；需重点回归连续长句、较快语速、短暂停连读这些场景。

- [x] 【输入成功判定】实际已经进入输入框的文本，不应再被错误记录为“注入失败”；无法稳定校验时应优先落到“注入未验证”

- [x] 【语音词库前缀编辑】语音词库中可直接编辑“强制命令前缀 / 强制输入前缀”；输入框有内容时按输入内容生效，留空即禁用，点击“恢复默认”才恢复资源默认值

- [x] 【语音词库布局精简】语音词库应分成“基础词条 + 命令分组”；除基础词条外，其余命令分组默认折叠，减少页面纵向长度；撤销、粘贴不再占用内置词库主区域

- [x] 【HUD 与实际一致】HUD 显示的输入/控制模式应与真实路由一致，不再出现“HUD 显示控制模式但实际输入了文本”
说明：已收紧 auto 路由逻辑，HUD 为控制模式时禁止 dictation fallback，需回归验证是否仍有控制模式下注入失败。

- [x] 【输入框识别】常见 App 的输入框应能稳定识别并进入输入模式，减少“未检测到输入框”

- [x] 【控制模式反馈】控制模式下未匹配命令时，应继续显示明确 HUD 提示

- [x] 【输入模式避让】输入模式下，HUD 应避让输入框、插入点和鼠标；鼠标压到 HUD 上时应及时重排，不挡住点击
说明：已加入鼠标避让锁定（0.8s）与目标位置鼠标占用判定，语音生成文字时需验证不再乱跳/瞬移。

- [x] 【输入文字可见性】输入模式下 HUD 不应遮住输入框中最新输入的文字，尤其是大文本输入框底部的最新一行

- [x] 【HUD 语言标记自动隐藏】当前语言标记（如 `中`）不应常驻显示；单语或双语场景下切换语言时，都应短暂显示一次

- [x] 【语言选择收拢】语音语言与词库编辑语言已改为下拉框，不再重复显示当前选中状态

- [x] 【词库示例精简】语音词库每项下方的“例如：...”示例行已移除，避免与输入框内容重复，也不应留下空白占位

- [x] 【输入模式命令前缀】输入模式下编辑命令需通过显式命令前缀触发；`命令 xxx` 已恢复生效

- [x] 【未匹配临时命令提示】输入模式下说“命令 xxx”但未命中命令时，会提示未匹配，且不会把整句误输入文本框

- [x] 【历史复制按钮】使用统计区域已拆分为 `复制诊断历史` 和 `复制 AI 分析提示`

- [x] 【历史单条复制】最近记录支持 hover 显示“复制单条”按钮（仅悬停可见，不占常驻空间）
