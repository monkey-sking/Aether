# Aether Pending Acceptance Checklist

## 当前重点验收（2026-03-13）

- [x] 【系统搜索输入】Spotlight / Siri / 通知中心搜索框可稳定进入输入态，并能把听写文本真正写入输入框
- [x] 【系统搜索宿主识别】`com.apple.notificationcenterui` 已纳入系统搜索宿主识别，Siri/系统搜索不应再被误判为普通 App
- [ ] 【输入成功判定】实际已经进入输入框的文本，不应再被错误记录为“注入失败”；无法稳定校验时应优先落到“注入未验证”
- [x] 【使用统计归因】语音历史中的 `appName` / `bundleIdentifier` 应与真实目标一致，不应把 Spotlight / Siri 误记成 `Aether`
- [ ] 【HUD 与实际一致】HUD 显示的输入/控制模式应与真实路由一致，不再出现“HUD 显示控制模式但实际输入了文本”
- [ ] 【输入模式避让】输入模式下，HUD 应避让输入框、插入点和鼠标；鼠标压到 HUD 上时应及时重排，不挡住点击
- [ ] 【HUD 语言标记自动隐藏】当前语言标记（如 `中`）不应常驻显示，仅在需要提示时短暂出现
- [ ] 【输入文字可见性】输入模式下 HUD 不应遮住输入框中最新输入的文字，尤其是大文本输入框底部的最新一行
- [ ] 【输入框识别】常见 App 的输入框应能稳定识别并进入输入模式，减少“未检测到输入框”
- [ ] 【控制模式反馈】控制模式下未匹配命令时，应继续显示明确 HUD 提示

## 本轮已交付，建议顺手回归

- [x] 【历史复制按钮】使用统计区域已拆分为 `复制诊断历史` 和 `复制 AI 分析提示`
- [x] 【输入失败统计】识别失败、未识别、目标无效等失败结果都会写入语音使用历史
- [x] 【使用统计口径】统计已按成功输入 / 识别失败 / 未识别 / 控制命令分开计算
- [x] 【剪贴板导入】从剪贴板导入语音词库时采用“合并”策略，不覆盖现有自定义
- [x] 【应用语言】App 语言切换已放到总览页，并影响 AI 提示词语言
- [x] 【HUD 提示时长】临时提示已改为按文案长度自适应
- [x] 【语音词库默认项可编辑】默认唤醒词/别名已放进输入框，用户可直接修改或删除
