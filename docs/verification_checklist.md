# Aether 验收清单 (Verification Checklist)

> 请勾选以下项目以确认功能正常。

## 0. 安装与权限 (Installation & Setup)
- [ ] **驱动激活**: 首次启动后，系统弹出 "System Extension Blocked" 并允许在安全性设置中启用。
- [x] **权限授予**: App 正确请求并获得“辅助功能”和“麦克风”权限。
- [x] **版本号**: 菜单栏 (Menu Bar) 中显示的版本号与安装包一致 (e.g. Version 1.0.2188)。

## 1. 核心语音功能 (Core Voice)
- [x] **普通听写 (Dictation)**: 在文本框（如 Notes, TextEdit）中，按住快捷键 (`Option + Space`) 或使用唤醒词说话，文字能正常上屏。
- [ ] **Siri/聚焦搜索 (Siri/Spotlight)**: 呼出 Siri 或 Spotlight，能直接进行语音输入。你好你好
- [ ] **命令控制 (Commands)**: 说“点击”、“向下”、“双击”等指令，鼠标能正确响应。
- [ ] **连续对话 (Continuous Mode)**: 开启“始终聆听” (`Option + Cmd + L`) 后，长时间不说话不应报错；说唤醒词 "Aether" / "艾瑟" 能触发指令。
- [ ] **快捷键验证**:
    - [x] `Option + Space`: 触发 PTT
    - [ ] `Option + Command + S`: 切换追踪 (Start/Stop)
    - [ ] `Option + Command + L`: 连接锁定/始终聆听

## 2. AirPods 交互 (AirPods)
- [ ] **按键触发 (Button Press)**: 按下 AirPods 捏合/柄部按键，能可靠触发/停止听写。
- [ ] **头部动作 (Head Gestures)**: (如果开启) 点头/摇头能触发对应动作。
- [ ] **媒体抢占**: 连接 AirPods 时，按键不会错误地启动 Apple Music。

## 3. HUD 界面 (HUD UI)
- [x] **视觉修复 (No Artifacts)**: 它是圆角矩形，**绝对没有“四个脚” (方形伪影)**。
- [x] **文字清晰度 (Text Clarity)**: 文字加粗 (Semibold)，带阴影，在白色/复杂背景下依然清晰可见。
- [x] **动态效果**: 说话时，绿色的麦克风图标会有呼吸/缩放动画。
- [x] **位置跟随 (交互模式)**: 在**非输入状态**下，HUD 实时跟随鼠标。
- [x] **位置固定 (输入模式)**: 在**输入状态**下，HUD **保持静止**。
- [x] **国际化 (i18n)**:
    - [ ] 切换到中文环境时，显示“正在聆听...”、“已粘贴”、“空闲”。
    - [ ] 切换到英文环境时，显示 "Listening...", "Pasted", "Idle"。
- [x] **无冗余显示 (Clean UI)**: 主界面中不再显示“红色区域”的听写文本框，仅保留 HUD 反馈。

## 4. 交互优化 (Interactions)
- [ ] **PTT 手动唤醒**: 在“始终聆听”模式下，按下 PTT 快捷键应直接开始听写（无需说唤醒词），且松开后不应意外终端会话。
- [x] **HUD 智能避让**: HUD 应能自动移动位置，避免遮挡鼠标指针和正在输入的文本光标 (Caret)。
- [x] **HUD 自动跟焦**: 切换输入框或窗口时（即使鼠标不动），HUD 应自动“跳”到新光标附近。
- [x] **HUD 层级优先级**: HUD 应浮在 Spotlight、系统搜索框及全屏应用之上，不被遮挡。
- [x] **界面精简**: 主界面已移除“合盖传感器”行。

- [x] **无语音超时**: 在连续模式下，长时间不说话，HUD 应保持待机或自动重启监听，而不应显示红色的“识别错误 (Speech Error)”。
- [ ] **休眠唤醒**: Mac 休眠后再唤醒，Aether 能自动重连 AirPods 并恢复头部控制，无需重启 App。
- [ ] **资源占用**: 长时间运行后，内存占用应保持稳定 (< 200MB)，无明显泄漏。
