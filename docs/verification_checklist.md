# Aether 验收清单 (Verification Checklist)

> 请勾选以下项目以确认功能正常。

## 0. 安装与权限 (Installation & Setup)
- [ ] **驱动激活**: 首次启动后，系统弹出 "System Extension Blocked" 并允许在安全性设置中启用。
- [x] **权限授予**: App 正确请求并获得“辅助功能”和“麦克风”权限。
- [x] **版本号**: 菜单栏 (Menu Bar) 中显示的版本号与安装包一致 (e.g. Version 1.0.2188)。

## 1. 核心语音功能 (Core Voice)
- [x] **普通听写 (Dictation)**: 在文本框（如 Notes, TextEdit）中，按住快捷键或使用唤醒词说话，文字能正常上屏。
- [ ] **Siri/聚焦搜索 (Siri/Spotlight)**: 呼出 Siri 或 Spotlight，能直接进行语音输入。
- [ ] **命令控制 (Commands)**: 说“点击”、“向下”、“双击”等指令，鼠标能正确响应。
- [ ] **连续对话 (Continuous Mode)**: 开启“始终聆听”后，长时间不说话不应报错；说唤醒词 "Aether" / "艾瑟" 能触发指令。

## 2. AirPods 交互 (AirPods)
- [ ] **按键触发 (Button Press)**: 按下 AirPods 捏合/柄部按键，能可靠触发/停止听写。
- [ ] **头部动作 (Head Gestures)**: (如果开启) 点头/摇头能触发对应动作。
- [ ] **媒体抢占**: 连接 AirPods 时，按键不会错误地启动 Apple Music。

## 3. HUD 界面 (UI & Animation)
- [ ] **视觉样式**: 它是胶囊形状的，**没有直角** (圆角平滑)，背景无异常阴影。
- [ ] **动态效果**: 说话时，绿色的麦克风图标会有**呼吸/缩放动画**。
- [ ] **位置跟随 (交互模式)**: 在**非输入状态**（如指令控制）下，HUD 实时跟随鼠标。
- [ ] **位置固定 (输入模式)**: 在**输入状态**（如打字时），HUD **保持静止**，不跟随鼠标乱动。
- [ ] **国际化 (i18n)**:
    - [ ] 切换到中文环境/中文输入时，显示“正在聆听...”、“已粘贴”。
    - [ ] 切换到英文环境时，显示 "Listening...", "Pasted"。

## 4. 稳定性 (Stability)
- [ ] **无语音超时**: 在连续模式下，长时间不说话，HUD 应保持待机或自动重启监听，而不应显示红色的“识别错误 (Speech Error)”。
- [ ] **休眠唤醒**: Mac 休眠后再唤醒，Aether 能自动重连 AirPods 并恢复头部控制，无需重启 App。
- [ ] **资源占用**: 长时间运行后，内存占用应保持稳定 (< 200MB)，无明显泄漏。
