# Aether Pending Acceptance Checklist

## 当前重点验收（2026-03-13）

- [ ] 【输入成功判定】实际已经进入输入框的文本，不应再被错误记录为“注入失败”；无法稳定校验时应优先落到“注入未验证”
- [ ] 【HUD 与实际一致】HUD 显示的输入/控制模式应与真实路由一致，不再出现“HUD 显示控制模式但实际输入了文本”
说明：已收紧 auto 路由逻辑，HUD 为控制模式时禁止 dictation fallback，需回归验证是否仍有控制模式下注入失败。


- [ ] 【语音词库前缀编辑】语音词库中可直接编辑“强制命令前缀 / 强制输入前缀”；输入框有内容时按输入内容生效，留空即禁用，点击“恢复默认”才恢复资源默认值

- [ ] 【语音词库布局精简】语音词库应分成“基础词条 + 命令分组”；除基础词条外，其余命令分组默认折叠，减少页面纵向长度；撤销、粘贴不再占用内置词库主区域



## 历史功能，待后续统一回归

- [ ] 【头势识别】点头/摇头的稳定性、阈值和误触控制需要再做一次完整回归
- [ ] 【头势提示音】点头/摇头成功后的提示音需要确认体验是否合适
- [ ] 【耳机按钮动作】耳机单击/双击/三击不应再触发 Aether 动作
- [ ] 【浏览器全屏视频 HUD】浏览器全屏播放视频时 HUD 应自动隐藏，退出后应恢复
- [ ] 【浏览器普通全屏误隐藏】普通网页全屏不应误触发 HUD 隐藏





## 本轮已交付，建议顺手回归
- [x] 【输入框识别】常见 App 的输入框应能稳定识别并进入输入模式，减少“未检测到输入框”
- [x] 【控制模式反馈】控制模式下未匹配命令时，应继续显示明确 HUD 提示
- [x] 【输入模式避让】输入模式下，HUD 应避让输入框、插入点和鼠标；鼠标压到 HUD 上时应及时重排，不挡住点击
说明：已加入鼠标避让锁定（0.8s）与目标位置鼠标占用判定，语音生成文字时需验证不再乱跳/瞬移。

- [x] 【输入文字可见性】输入模式下 HUD 不应遮住输入框中最新输入的文字，尤其是大文本输入框底部的最新一行

- [x] 【HUD 语言标记自动隐藏】当前语言标记（如 `中`）不应常驻显示；单语或双语场景下切换语言时，都应短暂显示一次

- [x] 【语言选择收拢】语音语言与词库编辑语言已改为下拉框，不再重复显示当前选中状态
- [x] 【词库示例精简】语音词库每项下方的“例如：...”示例行已移除，避免与输入框内容重复，也不应留下空白占位
- [x] 【输入模式命令前缀】输入模式下编辑命令需通过显式命令前缀触发；`命令 xxx` 已恢复生效
- [x] 【未匹配临时命令提示】输入模式下说“命令 xxx”但未命中命令时，会提示未匹配，且不会把整句误输入文本框

- [x] 【历史复制按钮】使用统计区域已拆分为 `复制诊断历史` 和 `复制 AI 分析提示`
- [ ] 【历史单条复制】最近记录支持 hover 显示“复制单条”按钮（仅悬停可见，不占常驻空间）
- [x] 【输入失败统计】识别失败、未识别、目标无效等失败结果都会写入语音使用历史
- [x] 【使用统计口径】统计已按成功输入 / 识别失败 / 未识别 / 控制命令分开计算
- [x] 【剪贴板导入】从剪贴板导入语音词库时采用“合并”策略，不覆盖现有自定义
- [x] 【应用语言】App 语言切换已放到总览页，并影响 AI 提示词语言
- [x] 【HUD 提示时长】临时提示已改为按文案长度自适应
- [x] 【语音词库默认项可编辑】默认唤醒词/别名已放进输入框，用户可直接修改或删除
- [x] 【AI 提示词上下文】复制 AI 分析提示时会附带当前自定义 App 规则 JSON 作为参考上下文
- [x] 【自定义 App 规则剪贴板】自定义 App 规则已支持整组复制 / 从剪贴板合并导入


- [x] 【系统搜索输入】Spotlight / Siri / 通知中心搜索框可稳定进入输入态，并能把听写文本真正写入输入框
- [x] 【系统搜索宿主识别】`com.apple.notificationcenterui` 已纳入系统搜索宿主识别，Siri/系统搜索不应再被误判为普通 App

- [x] 【使用统计归因】语音历史中的 `appName` / `bundleIdentifier` 应与真实目标一致，不应把 Spotlight / Siri 误记成 `Aether`
