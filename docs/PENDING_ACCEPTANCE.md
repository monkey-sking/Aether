# Aether Pending Acceptance Checklist

## 当前重点验收（2026-03-14）

- [ ] 【耳机麦克风切换】连接/断开耳机后应自动跟随正确的输入设备；麦克风列表只显示真实可选设备
  验证重点：热插拔、播放设备切换、左右耳切换、识别中路由切换

- [ ] 【AirPods 语音稳定性】AirPods 作为输入时语音功能应稳定工作，不应出现 HUD 已切耳机但语音无响应
  验证重点：单耳/双耳、启动时已戴耳机、切回普通麦克风

- [ ] 【耳机启动不卡顿】戴耳机启动时不应卡顿或因耳机初始化导致语音链路连环重启
  验证重点：戴耳机冷启动体感、HUD 刷新、语音首次可用时间

- [ ] 【启动时耳机自动开启】启动时若耳机已连接且"自动开启"已打开，应立即生效（语音输入/控制/头控三类）
  验证重点：冷启动时耳机已连接，三类自动开启是否都立即执行

## 历史功能，待后续回归

- [ ] 【头势识别】点头/摇头稳定性、阈值和误触控制
- [ ] 【头势提示音】点头/摇头成功后的提示音体验
- [ ] 【耳机按钮动作】耳机单击/双击/三击不应触发 Aether 动作

- [ ] 【浏览器普通全屏误隐藏】普通网页全屏不应误触发 HUD 隐藏
