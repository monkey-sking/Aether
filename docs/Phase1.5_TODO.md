## **3. 语音控制独立 (Voice-Only Control) [已部分落地]**
- [ ] **去除 PTT 热键依赖**
    - [x] 常驻语音监听默认开启 (Build 1918)
    - [ ] **智能唤醒策略 (Context-Aware Wake)**
        - [x] **待机状态**：在 Wake Word 模式下需要先说唤醒词
        - [x] **连指令窗口**：唤醒后已有 keep-awake window，窗口内无需再次唤醒
        - [x] **注视免唤醒**：已有 gaze wake 开关与基础实现
        - [x] **输入与操作状态区分 (Context-Aware Mode)**：已有 typing-aware 的听写 / 指令分路，当前主要剩稳定性与边界回归
- [x] **核心语音指令**
    | 指令 | 功能 |
    |------|------|
    | `开始` / `start` | 激活头部控制 |
    | `停止` / `stop` | 暂停头部控制 |
    | `校准` / `recenter` | 重置中心点 |
    | `悬停开` / `dwell on` | 开启 Dwell Click |
    | `悬停关` / `dwell off` | 关闭 Dwell Click |
- [x] **滚动语音指令 (Scroll)**
    | 指令 | 功能 |
    |------|------|
    | `向上滚` / `scroll up` | 向上滚动一段 |
    | `向下滚` / `scroll down` | 向下滚动一段 |
    | `到顶` / `top` | 滚动到页首 |
    | `到底` / `bottom` | 滚动到页尾 |
- [x] **拖拽语音指令 (Drag & Drop)**
    | 指令 | 功能 |
    |------|------|
    | `拖住` / `drag` | 按下鼠标左键（开始拖拽） |
    | `放下` / `drop` | 释放鼠标左键（结束拖拽） |
- [x] **App 打开与切换 (MVP 已落地)**
    - [x] 支持 `打开 Safari` / `open Safari` / `切到 Finder` 这类常见 App 的打开与前置
    - [x] 仅支持 `activationPolicy == .regular` 的常见 App，暂不覆盖 helper / menu bar / agent app
    - [x] 动作词与 App 名已拆开解析，并统一落到 `bundleIdentifier`
    - [x] 已有独立于 `VoiceLexicon` 的 App alias / resolver 能力，也支持手动补充自定义别名
    - [ ] 后续边界：窗口级 / 标签级 / 工作区级跳转仍不做；更复杂的中英混合别名与输入态保护继续补齐
- [ ] **全文优化上下文 (Rewrite Context)**
    - [ ] **MVP 范围**
        - [ ] 将 `全文优化 / 全文纠错优化` 从单次改写升级为“围绕写作任务工作的连续优化”
        - [ ] 以“同一篇内容 + 当前写作场景”作为主语义，而不是 `PID`、单一 App 或单次调用
        - [ ] 支持至少 4 类场景：即时沟通、正式表达、技术写作、结构化输入
        - [ ] 同一篇内容在短时间内连续优化时，复用短期上下文而不是每次从零开始
    - [ ] **长期偏好**
        - [ ] 按场景沉淀用户长期偏好，例如更口语、更正式、少改结构、保留术语
        - [ ] 长期偏好优先保存为可解释规则，而不是无边界保存历史全文
    - [ ] **隔离与回退**
        - [ ] 即时沟通与正式表达之间默认隔离，技术写作与普通表单之间默认隔离
        - [ ] 低置信度时回退到保守无上下文改写，不强行继承旧任务
        - [ ] App、窗口标题、项目目录只作为辅助信号，不直接决定上下文继承
    - [ ] **用户控制与可观测性**
        - [ ] 为 Rewrite Context 提供独立开关
        - [ ] 支持分别清空短期上下文与长期偏好
        - [ ] 在 Insights 中区分短期上下文命中、长期偏好命中与无上下文回退
    - [ ] **设计输入**
        - [ ] 详细规则见 `docs/specs/rewrite-context/`

## **验证标准 (Definition of Done)**

1. [ ] **零键鼠启动**：戴上 AirPods 后，无需任何键鼠操作即可开始控制光标
2. [ ] **语音全覆盖**：所有控制功能均可通过语音指令完成
3. [ ] **滚动能力**：可通过语音或头部倾斜完成页面滚动
4. [ ] **拖拽能力**：可通过语音或捏合手势完成拖拽操作
5. [ ] **首次引导**：新用户可通过语音完成权限授予流程
6. [ ] **App 导航能力**：用户可通过语音稳定地打开常用 App、切换到目标 App，并在中英混合说法下保持较高识别率
