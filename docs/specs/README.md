# Project Aether Spec 文档

本目录包含 Project Aether 的结构化 Spec 文档。

## 可用 Specs

### [Rewrite Context](rewrite-context/)

面向 `全文优化 / 全文纠错优化` 的上下文模型规格，包含：
- 用户场景优先的上下文语义
- 场景类型、任务连续性、长期偏好三层模型
- v1 的信号优先级、隔离规则与实现任务拆分

**目标**：
- 让全文优化从单次改写升级为连续写作辅助
- 把“同一篇内容”和“当前写作场景”定义为主语义
- 把 App、窗口、目录降级为辅助信号

### [Project Audit Improvements](project-audit-improvements/)

基于全面代码审核的改进计划，包含：
- 18个详细需求（P0/P1/P2优先级）
- 完整技术设计方案
- 150+可执行任务清单
- 20个正确性属性用于属性测试

**目标**：
- 实现滚动和拖拽功能
- 提升代码质量从 7.5/10 到 9/10
- 测试覆盖率从 0% 到 70%
- 建立 CI/CD 流程

**预计工作量**：约 55 个工作日

## Spec 工作流

所有 spec 文档遵循以下结构：

1. **requirements.md** - 需求文档（EARS格式验收标准）
2. **design.md** - 设计文档（架构、组件、接口、正确性属性）
3. **tasks.md** - 任务清单（可执行任务、需求追溯、测试任务）

## 原始 Spec 文件

完整的 spec 文件位于 `.kiro/specs/` 目录，由 Kiro spec 工作流管理。

本目录中的文档是为了方便查看和协作而创建的副本。
