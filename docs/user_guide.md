# Aether 使用说明

这份说明面向第一次使用 Aether 的普通用户。

Aether 主要有两类能力：

- `头控指针`：用兼容耳机的头部姿态控制光标
- `语音输入与语音控制`：用说话来输入文字，或执行点击、滚动、拖拽等命令

你不需要一次把所有功能都打开。最简单的上手方式是：

1. 先把权限开齐
2. 先试 `语音输入`
3. 再试 `语音控制`
4. 最后再按需打开 `头控指针`

## 开始前

建议先确认下面几件事：

- App 安装在 `/Applications/Aether.app`
- Mac 已授予 `辅助功能`、`麦克风`、`语音识别` 权限
- 如果你想使用头控，请连接支持头部姿态的兼容耳机

如果你是第一次打开 Aether，先进入 `总览` 页面，看最上方的 `准备情况`。这里会直接告诉你哪些项目还没完成。

## 第一次设置

打开 Aether 后，按这个顺序做：

### 1. 完成准备情况

在 `总览` 页面确认这几项已经就绪：

- `辅助功能`
- `麦克风`
- `语音识别`
- 至少一个可用麦克风设备

如果某一项没完成，直接点页面里的按钮去开启。

### 2. 先决定你怎么说话

在 `总览` 里的 `语音基础` 卡片里，你会看到 3 种唤起方式：

- `按住说话`
  - 只有按住快捷键时才识别
  - 适合刚开始使用，最稳妥
- `唤醒词`
  - 先说唤醒词，再继续讲话
  - 适合免手动，但不想一直开着麦克风
- `免提`
  - 持续待命
  - 最方便，但更耗电，也更依赖安静环境

如果你不确定选哪个，先用 `按住说话`。

### 3. 选择要开哪一类语音能力

Aether 把语音拆成两个独立开关：

- `语音输入`
  - 用来说文字
- `语音控制`
  - 用来执行点击、滚动、拖拽、切换之类的操作

你可以只开其中一个，也可以两个都开。

建议第一次先开：

- `语音输入`：开
- `语音控制`：开
- `头控指针`：先关，熟悉后再开

## 最常用的功能

### 1. 语音输入

适合写消息、记笔记、回邮件、在输入框里说话出字。

常见用法：

1. 点进一个输入框
2. 用你选定的方式唤起语音
3. 直接说话

如果你想调语言、麦克风、唤起方式，先看：

- `总览 > 语音基础`

### 2. 语音控制

适合在不方便用手的时候执行操作。

常见口令示例：

| 功能 | 示例 |
| :--- | :--- |
| 点击 | `点击` / `click` |
| 双击 | `双击` / `double click` |
| 右键 | `右键` / `right click` |
| 向上滚动 | `向上` / `scroll up` |
| 向下滚动 | `向下` / `scroll down` |
| 回到顶部 | `到顶` / `top` |
| 到底部 | `到底` / `bottom` |
| 开始拖拽 | `拖` / `drag` |
| 放下 | `放` / `drop` |
| 粘贴 | `粘贴` / `paste` |
| 撤销 | `撤销` / `undo` |
| 重新校准 | `校准` / `recenter` |

如果你想知道当前 App 还能用哪些命令，打开：

- `语音 > 应用快捷键`
- 菜单栏里的 `快捷键面板`

### 3. 头控指针

这是 Aether 里更“进阶”的能力。建议你先把语音用顺，再开头控。

打开方式：

1. 连接兼容耳机
2. 在 `总览` 里打开 `头控指针`
3. 如果需要，打开 `显示姿态引导`

什么时候需要 `校准`：

- 光标总是偏到一边
- 你刚换了坐姿
- 屏幕位置明显变了

如果头控已经打开，但没反应，优先检查：

- 耳机是否真的连接到当前这台 Mac
- 是否是支持头部姿态的兼容耳机
- `辅助功能` 是否已授权

### 4. 快捷键面板

如果你不记得命令名，可以直接用快捷键面板。

它适合两种场景：

- 看当前 App 有哪些常用快捷键
- 不确定该说什么时，先看面板再说

最直接的入口是菜单栏里的 `快捷键面板`。

另外，主窗口里的 `语音 > 应用快捷键` 页面也能帮助你查看当前应用可用的快捷键和命令。

## 进阶设置

当你已经能稳定使用以后，再看下面这些页面。

### `语音 > 语音词库`

这里可以调整：

- 唤醒词
- 强制命令前缀
- 强制输入前缀
- 各语言下的命令说法

如果你经常说某个词但识别不到，先来这里改，而不是反复适应默认词。

### `语音 > 应用快捷键`

这里会显示前台应用当前可读到的快捷键和常用控制项。

适合：

- 浏览器
- 编辑器
- 终端
- 菜单项比较完整的原生 App

### `语音 > 语音统计`

这里用于查看语音输入和语音控制的历史、统计和诊断信息。

如果你只是普通使用，不需要天天打开。

### `控制 > 头部动作`

这里可以调整：

- `热区规则`
- `头部动作（点头 / 摇头）`
- 调试和历史记录

这一页更适合已经熟悉头控的人。

## 日常建议

- 刚开始先用 `按住说话`
- 先把 `语音输入` 用顺，再开 `语音控制`
- 头控适合在手不方便、但头部姿态比较稳定的时候用
- `免提` 模式最省操作，但也最依赖环境安静
- 经常用的说法不匹配时，优先去 `语音 > 语音词库` 调整

## 常见问题

### 1. 我点了开关，但还是没反应

先回到 `总览` 看 `准备情况` 是否全部完成。

最常见的原因是：

- `辅助功能` 没开
- `麦克风` 没开
- `语音识别` 没开
- 当前没有可用麦克风

### 2. 菜单栏显示可以用，但主窗口里又说权限没开

先确保你运行的是安装在 `/Applications` 里的 Aether。

如果权限状态还是对不上，请看：

- `docs/PERMISSION_TROUBLESHOOTING.md`

### 3. 说话没有出字

先检查：

- `语音输入` 是否开启
- 你是否真的在输入框里
- 麦克风是否选对
- 当前唤起方式是不是 `按住说话`

如果你用的是 `按住说话`，需要一直按住快捷键说话，松开就会停止。

### 4. 说话能听到，但命令不执行

先检查：

- `语音控制` 是否开启
- 当前是不是处在更适合输入文字的场景
- 你说的命令是否能在 `语音词库` 或 `应用快捷键` 里找到

### 5. 头控指针没动

先检查：

- 兼容耳机是否连接到这台 Mac
- `头控指针` 是否真的开启
- 是否需要重新 `校准`
- `辅助功能` 是否已授权
