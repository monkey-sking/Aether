# Aether 使用指南

这份文档面向第一次打开 Aether 的普通用户。目标不是把所有能力一次讲完，而是让你按最少步骤把它真正用起来。

## 先记住一件事

Aether 主要有三层：

- `语音输入`：把说话变成文字
- `语音控制`：把说话变成点击、滚动、拖拽等动作
- `头控指针`：用兼容耳机的头部姿态控制光标

第一次使用时，建议顺序永远是：

1. 先把权限装好
2. 先试 `语音输入`
3. 再试 `语音控制`
4. 最后再开 `头控指针`

## 开始前

先确认这几件事：

- Aether 已安装在 `/Applications/Aether.app`
- `辅助功能`、`麦克风`、`语音识别` 已授权
- 如果要用头控，兼容耳机已经连接到这台 Mac

打开 App 后，先看 `总览` 页最上方的 `准备情况`。那里会直接告诉你缺了什么。

## 第一次上手

### 1. 先把准备情况补齐

在 `总览` 页确认这几项都已完成：

- `辅助功能`
- `麦克风`
- `语音识别`
- 至少一个可用麦克风设备

如果有项目没完成，直接点页面里的按钮去开启。

### 2. 先选一种说话方式

在 `总览 > 语音基础` 里，你会看到三种方式：

- `按住说话`
  - 只有按住快捷键时才识别
  - 最稳妥，最适合第一次使用
- `唤醒词`
  - 先喊唤醒词，再继续讲话
  - 适合不想一直按键的人
- `免提`
  - 持续待命
  - 最方便，但更依赖安静环境

如果你不确定，先用 `按住说话`。

### 3. 先开语音输入

语音输入适合写消息、记笔记、回邮件、在输入框里直接说话。

基本流程：

1. 点进一个输入框
2. 用你选定的方式唤起语音
3. 直接说话

建议第一次先只关注它能不能稳定出字。

### 4. 再开语音控制

语音控制适合不方便用手的时候执行操作。

常见口令：

| 功能 | 示例 |
| :--- | :--- |
| 点击 | `点击` / `click` |
| 双击 | `双击` / `double click` |
| 右键 | `右键` / `right click` |
| 向上滚动 | `向上` / `scroll up` |
| 向下滚动 | `向下` / `scroll down` |
| 开始拖拽 | `拖` / `drag` |
| 放下 | `放` / `drop` |
| 撤销 | `撤销` / `undo` |
| 重新校准 | `校准` / `recenter` |

如果你想先看当前 App 还支持什么命令，打开：

- `语音 > 应用快捷键`
- 菜单栏里的 `快捷键面板`

### 5. 最后再开头控指针

头控指针更进阶，建议你先把语音部分用顺后再开。

打开方式：

1. 连接兼容耳机
2. 在 `总览` 里打开 `头控指针`
3. 需要的话再打开 `显示姿态引导`

什么时候该 `校准`：

- 光标总是偏到一边
- 你换了坐姿
- 屏幕位置明显变化

如果头控已经开了但没动，先查：

- 耳机是否真的连接到当前这台 Mac
- 是否是支持头部姿态的兼容耳机
- `辅助功能` 是否已授权

## 最常用的页面

### `语音 > 语音词库`

这里可以改：

- 唤醒词
- 命令前缀
- 输入前缀
- 各语言下的命令说法

如果你经常说某个词但识别不到，先来这里改。

### `语音 > 应用快捷键`

这里显示前台应用当前能识别到的快捷键和常用控制项。

适合：

- 浏览器
- 编辑器
- 终端
- 菜单项比较完整的原生 App

### `语音 > 语音统计`

这里用于查看语音输入和语音控制的历史、统计和诊断信息。

普通用户不需要天天打开。

### `控制 > 头部动作`

这里可以调整：

- `热区规则`
- `点头 / 摇头` 行为
- 调试和历史记录

这一页更适合已经熟悉头控的人。

### `About`

这里负责：

- 激活
- 试用
- 设备管理
- 更新通道切换
- 手动检查更新

如果你找不到更新入口，先去这里看。

## 日常建议

- 第一次先用 `按住说话`
- 先把 `语音输入` 用顺，再开 `语音控制`
- 头控适合在姿态稳定、但手不方便的时候使用
- `免提` 最省操作，也最依赖环境
- 命令说法不匹配时，优先去 `语音 > 语音词库` 调整

## 常见问题

### 1. 我点了开关，但还是没反应

先回到 `总览` 看 `准备情况`。

最常见的原因是：

- `辅助功能` 没开
- `麦克风` 没开
- `语音识别` 没开
- 当前没有可用麦克风

### 2. 菜单栏显示正常，但主窗口提示权限没开

先确认你运行的是安装在 `/Applications` 里的 Aether。

如果还是不对，看：

- `docs/PERMISSION_TROUBLESHOOTING.md`

### 3. 说话没有出字

先检查：

- `语音输入` 是否开启
- 你是否真的在输入框里
- 麦克风是否选对
- 当前唤起方式是不是 `按住说话`

如果你用的是 `按住说话`，需要一直按住快捷键，松开就会停止。

### 4. 说话能听到，但命令不执行

先检查：

- `语音控制` 是否开启
- 当前是不是更适合输入文字的场景
- 你说的命令是否能在 `语音词库` 或 `应用快捷键` 里找到

### 5. 头控指针没动

先检查：

- 兼容耳机是否连接
- `头控指针` 是否真的开启
- 是否需要重新 `校准`
- `辅助功能` 是否已授权
